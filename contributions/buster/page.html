hi. i'm buster.

i made this whole thing on a whim. the idea is simple:
anyone can add their own page. fork the repo, drop in your html,
open a pull request, and if it passes the checks it gets merged automatically.
no gatekeeping. no waiting on me to approve stuff.

this page is contribution #1 from philadelphia. proof of concept.
if you're reading this, the experiment is working.

want in? make a folder under contributions/your-name/
add a meta.json and a page.html. that's literally it.
check the contributing guide in the repo if you want the full rules.
